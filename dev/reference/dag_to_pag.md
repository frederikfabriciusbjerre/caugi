# Construct the PAG of a DAG with latent variables

Returns the Partial Ancestral Graph a DAG induces over its observed
variables once `latents` are marginalized out and `selection` is
conditioned on: what FCI recovers from data generated by `cg` given a
perfect conditional-independence oracle.

## Usage

``` r
dag_to_pag(cg, latents = NULL, selection = NULL)
```

## Arguments

- cg:

  A `caugi` object of class `"DAG"` or `"AG"`.

- latents:

  Character vector of nodes to marginalize out.

- selection:

  Character vector of selection nodes to condition on. Conditioning on a
  common child of two nodes joins them by `---`.

## Value

A `caugi` object of class `"PAG"` over the remaining nodes.

## Details

[`condition_marginalize()`](https://caugi.org/dev/reference/condition_marginalize.md)
gives the MAG over the remaining nodes (Richardson and Spirtes 2002,
Section 4.2.1), and
[`mag_to_pag()`](https://caugi.org/dev/reference/mag_to_pag.md) gives
the PAG of its Markov equivalence class.

## References

Richardson, T. and Spirtes, P. (2002). Ancestral graph Markov models.
*The Annals of Statistics*, 30(4), 962-1030.

## Examples

``` r
dag <- caugi(U %-->% X, U %-->% Y, X %-->% Y, W %-->% X, class = "DAG")
dag_to_pag(dag, latents = "U")
#> <caugi object; 3 nodes, 3 edges; simple: TRUE; session=0x5b8a90a80600>
#>   graph_class: PAG
#>   nodes: X, W, Y
#>   edges: Wo-oY, Xo-oW, Xo-oY

# Selection bias: conditioning on a common child.
dag_to_pag(caugi(X %-->% S, Y %-->% S, class = "DAG"), selection = "S")
#> <caugi object; 2 nodes, 1 edges; simple: TRUE; session=0x5b8a8bcd4a50>
#>   graph_class: PAG
#>   nodes: X, Y
#>   edges: Xo-oY
```
