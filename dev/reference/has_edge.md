# Are two nodes adjacent?

Checks whether any edge joins `X` and `Y`, whatever its type and
direction.

## Usage

``` r
has_edge(cg, X, Y)
```

## Arguments

- cg:

  A `caugi` object.

- X, Y:

  Node names, one each.

## Value

`TRUE` if an edge joins `X` and `Y`, otherwise `FALSE`.

## Examples

``` r
cg <- caugi(A %-->% B, B %<->% C, class = "ADMG")
has_edge(cg, "A", "B") # TRUE
#> [1] TRUE
has_edge(cg, "B", "A") # TRUE
#> [1] TRUE
has_edge(cg, "A", "C") # FALSE
#> [1] FALSE
```
